# Privacy Policy: Follow-up Agent

This is a personal tool used only by its owner, Hiu Cheung (hiu3648@gmail.com).

- It reads Gmail threads that the owner has labeled `founders`, to check whether a reply arrived.
- It sends one summary email, only to the owner's own address.
- It can write a tracking table to the owner's own Google Sheet.
- Data stays on the owner's computer (a local file) and in the owner's Google account.
  Nothing is sold, shared, or sent to any other person or service.
- Access can be removed at any time at https://myaccount.google.com/permissions
